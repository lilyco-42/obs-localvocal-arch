# i18n 说明（多语言文档与本地化命令）

本页说明仓库的国际化范围、语言码约定、本地化命令 `obs-captions-help`，以及如何补一门新语言。姊妹页：[字幕翻译与多语言识别](TRANSLATION.md)。

## 1. 覆盖范围

| 内容 | 语言数 | 位置 |
| --- | --- | --- |
| 项目首页 / 30 秒快速入门 | 12 | 根 [README.md](../README.md) + [docs/i18n/README.md](i18n/README.md) 索引下各目录 README.md |

| 原理与实测 | 仅中文 | [docs/ARCHITECTURE.md](ARCHITECTURE.md) |
| i18n 说明 / 字幕翻译 | 仅中文 | 本页、[TRANSLATION.md](TRANSLATION.md) |

12 种语言对照上游插件自带的 locale：`ar-SA.ini` / `de-DE.ini` / `en-GB.ini` / `en-US.ini` / `es-ES.ini` / `fr-FR.ini` / `hi-IN.ini` / `ja-JP.ini` / `ko-KR.ini` / `pl-PL.ini` / `pt-BR.ini` / `ru-RU.ini` / `zh-CN.ini`。

> 为什么 GUIDE / ARCHITECTURE 不翻译：它们含大量设置键、日志原文、ABI 与源码行号，翻译会破坏可检索性。命令、路径、设置键与**输出 token**（`SETUP_OK` / `VERIFY_OK` / `DONE` / `LDD_OK`）在所有语言里一律保持原文。

## 3. 页面切换器

每个翻译页的第 3 行是一条 12 项切换器，结构示意如下（用箭头代替链接语法，避免示例被当成真实链接）：

```text
中文 → ../../../README.md · English → ../en/README.md · 日本語 → ../ja/README.md · … · Polski → ../pl/README.md
```

规则：`docs/i18n/<代码>/` 下，指向兄弟语言用 `../<代码>/<文件名>`；指向中文源文档用 `../../../README.md`（README）或 `../../QUICKSTART.md`（QUICKSTART）；当前语言用同目录文件名。根中文文档用正向链接 `docs/i18n/<代码>/…`。增删语言时必须同步所有页的这一行，见第 6 节。

## 4. obs-captions-help（本地化命令）

安装后随仓库提供，零 npm 依赖：

```bash
obs-captions-help --list      # 列出全部语言码与名称
obs-captions-help en          # 用英文打印 5 步快速入门
obs-captions-help ja          # 日文
obs-captions-help             # 不传代码则自动识别
CAPTION_UI_LANG=fr obs-captions-help   # 显式指定
```

自动识别优先级：命令行代码 → `CAPTION_UI_LANG` → `LC_ALL` → `LC_MESSAGES` → `LANG` → `en`。`LANG=zh_CN.UTF-8` → `zh`；`LANG=ja_JP.UTF-8` → `ja`；`LANG=pt_BR.UTF-8` → `pt-BR`；`LANG=de_DE.UTF-8` → `de`。未匹配时兜底英文（而不是静默变中文），避免非中文用户看不懂引导。

`install.sh` 结束时的「下一步」与 PATH 提示都走同一个本地化模块（分别执行 `node "$HELPER_DIR/help.mjs" --next "$BIN_DIR"` 与 `--path "$BIN_DIR"`），所以安装引导会跟随你的系统语言。找不到命令时把 `~/.local/bin` 加入 PATH：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

实现：`bin/obs-captions-help` 调用 `lib/help.mjs`（安装到 `$XDG_DATA_HOME/obs-captions/help.mjs`），消息表在 `MESSAGES` 里，共 12 份；语言码归一与自动识别在 `lib/lang.mjs`，由 `help.mjs` 与 `setup.mjs` 共用。安装器进度日志保持中文与机器可读 token，仅末尾引导与 PATH 提示本地化。

## 5. 两套语言不要混淆

| 变量 | 控制什么 | 默认 |
| --- | --- | --- |
| `CAPTION_UI_LANG` / `LANG` | 帮助文本、安装引导的语言 | `LANG`，兜底 `en` |
| `CAPTION_LANG` | Whisper 把**你说的语音**识别成哪种文字 | `zh` |
| `CAPTION_TRANSLATE=1` | Whisper 把识别结果翻译成英语字幕 | 关 |

文档语言与字幕语言彼此独立：日文系统照样可以出中文字幕，中文系统也能出英文字幕。详见 [TRANSLATION.md](TRANSLATION.md)。

## 6. 加一门新语言

1. 复制 `docs/i18n/en/{README.md,QUICKSTART.md}` 到 `docs/i18n/<代码>/`，逐段翻译；保留代码块、路径、设置键与输出 token。
2. 更新全部页第 3 行切换器，为新语言追加 README 与 QUICKSTART 两个链接（相对路径规则见第 3 节）。
3. 更新 [docs/i18n/README.md](i18n/README.md) 索引表、根 [README.md](../README.md) 顶部导航、本页第 1/2 节表格。
4. 在 `lib/help.mjs` 的 `MESSAGES` 加一份 `{ title, next, steps, tip }`、`PATH_HINTS` 加一条本地化 PATH 提示，并在 `lib/lang.mjs` 的 `UI_CODES` / `UI_NAMES` / `UI_ALIAS` / `CAPTION_ALIAS` 里登记。
5. 自检：`bash -n bin/*`、`node --check lib/*`、`obs-captions-help --list`、`obs-captions-help <代码>`、检查所有 Markdown 相对链接存在。
6. 若字幕也要显示该语言文字，确认系统装了相应字体（见 TRANSLATION.md 第 5 节）；阿拉伯语等 RTL 文字还需注意 OBS 文本源的排版限制。

## 7. 翻译约定

- 「说中文」「你好，欢迎来到我的直播间。」在示例里保留中文：演示的是中文识别，翻译成目标语言会让读者误以为要念目标语言。
- 术语统一：滤镜 filter、文本源 text source、场景 scene、画布 canvas、流式 partial / streaming、包装器 wrapper。
- `zh` 源文档是权威版本；其它语言与中文冲突时以中文为准，欢迎提 PR 修正。
- 不翻译的有：URL、sha256、`~/.config/obs-studio/...` 路径、设置键（`partial_group` 等）、日志行、`SETUP_OK` 一类 token。

## 8. 校验清单

```bash
bash -n install.sh uninstall.sh scripts/*.sh bin/*
node --check lib/*.mjs
obs-captions-help --list
obs-captions-help ar
CAPTION_UI_LANG=hi obs-captions-help
node lib/help.mjs --path /tmp/fakebin
```

再逐页检查第 3 行切换器的 12 个相对链接，以及 [docs/i18n/README.md](i18n/README.md) 索引表。
