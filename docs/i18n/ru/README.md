Субтитры на **китайском** в реальном времени в нижней части сцены OBS в Arch / CachyOS / совместимых Linux. Установка на уровне пользователя: без sudo, без AUR, без сборки.

## Быстрый старт за 30 секунд

Выполните эти четыре команды по порядку (при первом запуске скачается около 300 МБ).

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/lilyco-42/obs-localvocal-arch/main/install.sh)
obs-captions
obs-captions-setup
obs-captions-doctor
```

1. **Установка** — проверяет и распаковывает официальный `.deb` 0.6.2, добавляет недостающие ICU70 / OpenBLAS и скачивает многоязычную модель Whisper.
2. **Полностью закройте OBS** и запустите его заново через обёртку, чтобы плагин действительно загрузился.
3. **Во втором терминале** — создаёт или обновляет аудиофильтр и текстовый источник субтитров внизу экрана (идемпотентно, можно повторять).
4. **Скажите фразу по-китайски** в микрофон и запустите самопроверку. `VERIFY_OK` означает, что всё готово.

## Что делается

- Всё остаётся в вашем каталоге: плагин размещается в `~/.config/obs-studio/plugins/obs-localvocal/`, каталог `/usr` не изменяется.
- Распознавание выполняется локально на CPU через whisper.cpp — звук не покидает компьютер.
- Фильтр подключается к входу микрофона с `whisper_language_select=zh` и `partial_group=true`, поэтому частичный текст появляется примерно через 1,1 с.
- Субтитры — обычный текстовый источник OBS (`text_ft2_source_v2`): по центру внизу, белый текст с чёрной обводкой, размер подстраивается под разрешение сцены.
- Так как это источник сцены, его видят и зрители трансляции, и записанный файл — браузерный источник или окно поверх всех окон не нужны.

## Требования

- OBS 33.x (нужен `/usr/lib/libobs.so.30`)
- Arch / CachyOS / семейство Arch, x86_64
- `node >= 22` (встроенный WebSocket), `curl`, `patchelf`, `sha256sum`
- Шрифт CJK, например `noto-fonts-cjk`
