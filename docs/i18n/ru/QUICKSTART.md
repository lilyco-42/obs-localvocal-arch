> Другие языки: выполните `obs-captions-help <код>` (например `obs-captions-help ru`), чтобы вывести этот быстрый старт на вашем языке; `obs-captions-help --list` покажет все коды. См. также [i18n 说明](../../I18N.md) и [字幕翻译](../../TRANSLATION.md) — пока только на китайском.
**Цель:** говорить по-китайски → субтитры появляются в реальном времени внизу сцены OBS → зрители видят их в трансляции и записи.

## 0. Подготовка

- OBS 33.x и `node >= 22`; доступны `curl`, `patchelf`, `sha256sum`.
- Микрофон, который уже работает в OBS (Настройки → Аудио).
- Шрифт CJK, например `noto-fonts-cjk`, иначе вместо текста будут квадраты.
- `sudo`, `yay` и сборка из исходников **не** нужны.

## 1. Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/lilyco-42/obs-localvocal-arch/main/install.sh)
```

Повторный запуск безопасен: файлы с совпадающим sha256 берутся из кэша (`~/.cache/obs-localvocal-arch`). В конце скрипт выводит `DONE`.

## 2. Перезапуск OBS

Сначала **полностью закройте** уже запущенный OBS — плагины загружаются только при старте процесса. Затем запустите его через обёртку:

```bash
obs-captions
```

В журнале в `~/.config/obs-studio/logs/` должны появиться строки `plugin loaded successfully (version 0.6.2)` и `Loading whisper model from ...`.

## 3. Создание фильтра и источника субтитров

```bash
obs-captions-setup
```

Оставьте OBS запущенным и откройте другой терминал. Скрипт подключается к локальному obs-websocket, находит текущую сцену и вход микрофона, создаёт или обновляет фильтр `LocalVocal Transcription` и текстовый источник `LocalVocal Subtitles`, размещая его внизу сцены. Признак успеха — `SETUP_OK`.

## 4. Проверка

Скажите в микрофон **«你好，欢迎来到我的直播间。」** Сначала появится частичный текст, затем он закрепится в полном предложении. Затем:

```bash
obs-captions-doctor
```

## 5. Трансляция или запись

Просто нажмите «Начать запись» или «Начать трансляцию» в OBS. Если вы также захватываете экран или игру, перетащите `LocalVocal Subtitles` в начало списка источников, чтобы субтитры были поверх видео.

## 6. В следующий раз

```bash
obs-captions          # запустить OBS с плагином
obs-captions-setup    # необязательно: идемпотентно восстановить фильтр
```

OBS записывает фильтр в коллекцию сцен только при нормальном завершении, поэтому после сбоя или `kill -9` фильтр может пропасть — `obs-captions-setup` вернёт его на место.

## Что-то не работает?

| Симптом | Что проверить первым |
| --- | --- |
| Субтитров нет совсем | `obs-captions-doctor`; проверьте, не отключён ли микрофон; запустите `obs-captions-setup` снова |
| Плагин не загружается | Запускайте через `obs-captions`, а не `/usr/bin/obs`, и смотрите журнал |
| Квадраты вместо букв | Установите `noto-fonts-cjk` и повторите `obs-captions-setup` |
| Высокая загрузка CPU | Перейдите на `ggml-tiny-q5_1` или `ggml-base-q5_1`, см. руководство |
| Порт 4455 недоступен | Нужен перезапуск OBS; проверьте `server_enabled=true` в `config.json` |
