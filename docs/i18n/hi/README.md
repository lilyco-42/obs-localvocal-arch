## 30 सेकंड में तेज़ शुरुआत

ये चार कमांड क्रम से चलाएँ (पहली बार लगभग 300MB डाउनलोड होगा)।

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/lilyco-42/obs-localvocal-arch/main/install.sh)
obs-captions
obs-captions-setup
obs-captions-doctor
```

1. **इंस्टॉल** — आधिकारिक 0.6.2 `.deb` जाँचकर खोलता है, छूटी हुई ICU70 / OpenBLAS लाइब्रेरी जोड़ता है और बहुभाषी Whisper मॉडल डाउनलोड करता है।
2. **OBS को पूरी तरह बंद करें**, फिर रैपर से दोबारा खोलें ताकि प्लगइन वास्तव में लोड हो।
3. **दूसरे टर्मिनल में** — ऑडियो फ़िल्टर और नीचे वाला सबटाइटल टेक्स्ट सोर्स बनाता/अपडेट करता है (बार-बार चलाना सुरक्षित)।
4. **माइक में चीनी में बोलें**, फिर सेल्फ-चेक चलाएँ। `VERIFY_OK` का मतलब सब तैयार है।

## यह क्या करता है

- सब कुछ यूज़र डायरेक्टरी में: प्लगइन `~/.config/obs-studio/plugins/obs-localvocal/` में जाता है, `/usr` छुआ नहीं जाता।
- पहचान whisper.cpp से CPU पर लोकल चलती है — ऑडियो कभी मशीन से बाहर नहीं जाता।
- फ़िल्टर माइक इनपुट पर लगता है, `whisper_language_select=zh` और `partial_group=true` के साथ, इसलिए लगभग 1.1 सेकंड में अधूरा टेक्स्ट दिखता है।
- सबटाइटल सामान्य OBS टेक्स्ट सोर्स है (`text_ft2_source_v2`): नीचे मध्य में, सफ़ेद अक्षर काली आउटलाइन के साथ, कैनवास रेज़ोल्यूशन के अनुसार।
- चूँकि यह सीन का सोर्स है, लाइव दर्शक और रिकॉर्डिंग दोनों में वही दिखता है — न ब्राउज़र सोर्स, न ऑलवेज़-ऑन-टॉप विंडो।

## आवश्यकताएँ

- OBS 33.x (`/usr/lib/libobs.so.30` होना चाहिए)
- Arch / CachyOS / Arch परिवार, x86_64
- `node >= 22` (अंतर्निहित WebSocket), `curl`, `patchelf`, `sha256sum`
- CJK फ़ॉन्ट, जैसे `noto-fonts-cjk`
